## 本次纵向切片

1. **战斗**：双方 3×3、各最多 6 人、战前换位和条件战术、AP/PP 自动演算。GAS 属性、能力消耗、效果承担数值状态；游戏层实现双伤、两段控制、位移、地表、材质互动、双轨战利品。
2. **经营与探索**：雷恩/克萝伊二选一，另一人始终为伙伴；鉴定、议价、收购、修复、销赃印记处理、格子背包、出售、周报行情、周日房租、商店升级、步进地牢、父母遗物与坐标解锁、存档。
3. **Unity 可玩入口**：选择角色、当铺、编队、地牢、战斗、战利品、日志；原创背景、金属/羊皮纸风格界面、技能反馈、双血条与红蓝豆，明确 Spine 接口。

本次目标是可运行、可验证、可继续扩展的首章切片。AAA 成品的角色动画、全量剧情/关卡、配音音效和设备性能验收仍属于后续制作；不会把占位角色或未运行的 Unity 测试标为成品。

## 设计规则的明确化

| 设计点 | 当前实现约定 |
| --- | --- |
| 空间 | `slot = row * 3 + depth`；两方 depth=0 都是靠近中线的前排，视觉镜像。每方 9 格最多 6 人。 |
| 同时双伤 | 一次命中先快照白条与缓冲，再同时算白条、红条。打破白条的那一击仍按命中前缓冲算红伤；后续命中无缓冲。 |
| 无甲 | 未指定的无甲公式取基础伤害全额扣生命；破甲跨越 >0→0 时仅损失一次 1 PP。 |
| 破绽 | 失衡、定身、滑倒、冰封、麻痹、击倒和背刺开放甲缝。潮湿/油污本身是元素铺垫，不自动等于失衡。 |
| “100% 满额红条暴击” | 解释为穿甲分量不再被甲片缓冲削减，不额外发明随机暴击倍率。精密刺击在甲缝开放时保留白条；普通物理武器仍按双伤规则。 |
| 控制 | 满甲也能中一段控制；失衡封锁 PP 使用但不删除 PP。硬控跳过一次行动机会；铺垫控制采用目标行动机会计时。 |
| 冰 | 冰封目标受钝击时破甲分量 ×2.5，钝击碎冰；精密刺击不碎冰。 |
| 资源 | AP/PP 是一次遭遇的预算，不自动无限补充；行动顺序和同速顺序确定，耗尽或上限形成可解释的终局。 |
| 战利品 | 异魔/构装体死亡且护甲为 0 才产魔核；人形死亡且剩余护甲比例 ≥80% 才产完整盔甲。遗物触发寻亲线索。 |
| 经营 | 默认周一开始，周日交租；关店时自动尝试结租，不足进入失去店铺结局。价格/租金/天数属于首章平衡配置。 |
| 主角 | 主控身份提供不同经营优势与战术；未选兄妹仍在编队和故事中。 |
