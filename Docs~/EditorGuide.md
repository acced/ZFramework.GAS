# 编辑器

## 入口

`Window > ZFramework GAS > 技能编辑器` 是创作入口；`Window > ZFramework GAS > 运行时调试` 是观察当前单位的入口。库不再提供独立批量编辑、全局搜索、差异比较、引用查询或模块窗口。

## 最小创作路径

1. 主窗口新建空白 GameplayAbilityAsset。
2. 在详情里设置标签、参数、消耗和冷却。消耗与冷却均引用 GameplayEffectAsset。
3. 在动作视图中排列动作和条件分支。效果直接配置到「施加效果」动作；目标策略配置在 TargetQuery。
4. 需要实时表现时创建 SkillAnimationAsset，直接指定 AnimationClip 和时间轴时长；配置 Marker、Cue/标签窗口、命中窗口或音效。
5. 需要蓄力后付款时关闭 autoCommit，在真实提交点添加 CommitAbilityAction。
6. 按 F7 或「编译检查」。诊断可定位到字段、动作或 Marker；构建前自动运行全部资产检查。

动作仍支持增删、复制、跨分支移动、Undo/Redo 与稳定 ID。结构图用于查看和编辑能力、效果、表现资产的引用关系，保留自动布局、连线、选择和定位。没有重路由节点、书签、注释组、额外排列工具或模块调用图。

## 参数与扩展

参数声明只在技能自身维护。编辑器按稳定 ID 绑定参数，修改显示名不会破坏绑定。动态数值通过不可变 EffectEvaluationContext 传入，项目公式通过 IEffectCalculation 实现。没有模块局部变量或额外 SetByCaller 声明面板。

需要自定义动作时派生 SkillAction，并用 FlowField/FlowBranch 标注少量可编辑字段和子分支。工具库不附带伤害算法、弹射、投射物或区域逻辑。项目自定义轨道可扩展 SkillRuntimeTrack；无需为新玩法新增全局窗口或启动器。

## 预览与调试

预览使用隔离实例显示动画姿势、Cue/VFX、音效和查询范围，不执行一套模拟战斗，也不预测投射物命中和连锁分叉。实际技能结果在 Play Mode 中检查。

运行时窗口观察当前 ASC 的属性、计数标签、效果、授权、当前激活检查与任务时间。主编辑器可跟随实际任务播放位置，动作记录可定位到实际 ID。项目自行持有的独立 TaskHost 不再通过全局场景扫描汇总。

## 校验范围

配置错误在资产构建和发布前报告：非法标签、缺少效果、无效参数、循环效果引用、非法任务归属和时间轴窗口等。校验无规则禁用入口。F7 强制重建缓存，日常编辑采用变化触发的增量校验。

编译检查会构建内存定义并报告问题。首次 Grant 仍可能构建该资产的定义；这里没有离线可执行 Program 导出，也没有运行时脚本编译器。
