# 技能编辑器使用指南

**从斩击开始。** 在 `Tools → ZFramework GAS → 创建 BasicCombat 示例` 生成示例，打开「斩击」，双击时间轴 0.36 秒的「命中」，再双击「调用共享模块」标题。现在看到的两个出口分别施加强化和普通伤害。单击节点可在 Details 配置完整参数，图内可以直接修改效果、选敌类型等常用字段。用上方「上一级」返回。

![生成的斩击：条件分支、选敌和同一时刻的三目标预演](Images/EditorImprovements/flow-module.png)

- **写动作**：在「流程」用空格搜索动作，或从执行出口添加；把已有动作的输入连到目标出口可移入对应列表。右键支持重排、复制、删除、收藏类型。框选同一列表中的连续动作，右键「提取为共享模块」；调用节点可以反向内联。提取会把选中动作独占的内嵌效果及私有子效果一起移入模块；同一效果仍只有一份。还有其他动作或资产引用它时，编辑器会指出引用方并取消提取。此时可一起选中相关动作，或先把效果外置为共享资产，保留按同一定义叠层／移除的行为。内联或跨文件粘贴遇到私有效果时，先选择是否使用目标文件的独立副本。若灼烧等效果要在几个技能间叠层，取消并让相关动作都引用同一个独立效果资产。若选择副本，之后粘贴同一版本的来源会复用对应副本。原件、目标文件中的副本或其私有子效果改过后，再粘贴或内联会一次列出冲突。可保留目标数值、按来源当前数值生成新副本，或取消整个操作；这个决定适用于本次动作所引用的效果树。选择复用会记住这次接受的来源版本和目标配置；两者都没再变时不会重复询问。选择新副本会复制冲突根的全部私有子效果；原版本继续使用原树，独立的共享效果仍共用。同一批里还有第一次复制的效果时，另外确认它们是否可以分开叠层；取消会撤销整个操作。「创建副本」直接在列表中添加动作，不覆盖之前放进剪贴板的动作；右键「复制到剪贴板」才会替换剪贴板内容。批处理没有显式决策时会取消。提取前会检查 Prefab、场景和其他资产的实际引用；移动子资产会改变 GUID:fileID，移动前会列出原键。技能编辑器会沿用节点布局，外部存档或 Addressables 的间接键需要项目自行处理。撤销提取时，若另一个技能已经引用模块，文件会保留；重做时原路径被占用会使用新路径，不覆盖占用者。若某个文件被锁或无法恢复，只停止重放这个文件，同组其他文件继续处理；日志给出路径。重做失败时，原动作及私有效果恢复到技能；在这组撤销历史内再次撤销／重做，也不会生成空模块调用。模块和 .meta 的恢复副本在项目根目录 GASRecovery~/Modules，清理 Library 不会删除它们。这是使用方 Unity 项目根目录下的文件；如不需纳入版本控制，可在项目的 .gitignore 加一行 `/GASRecovery~/`。撤销恢复原件后，未被引用的修复副本会从技能文件分离，并保留在内存中；再次重做会接回同一个对象，因此后续对它的属性编辑仍可重做。对应历史被丢弃后才释放分离的对象。停放只在当前编辑器会话内有效：重启 Unity 会清空撤销历史，停放在内存里的对象不会写盘，重启后也不能再重做这次编辑。如果其他资产已引用某份副本，该资产与编辑历史保留原对象，技能再次内联时取独立副本。修复只把技能标记为待保存，不代为保存整个文件。失败日志会说明原动作已恢复、原本已内联，还是因所属资产不存在、槽位被改或内联异常而未恢复。通过 Tools → ZFramework GAS → 打开模块恢复目录可另存或分享；检查后可用「清理模块恢复副本…」清除。复制会生成新 ID，移动保留 ID。独立回调与取消分支不能接等待或能力归属任务。
- **调试**：Play 中在 `Window → ZFramework GAS → 运行时调试` 观察骑士。「单位」看属性和播放头；「事件」按类型或文字筛选，冻结后拖泳道回看，双击或选择记录定位；「监视」显示断点命中时的参数、目标、通道和查询结果。流程节点圆点或 F9 切换断点。Unity 在整帧边界暂停，当前调用栈中的同步动作仍可能继续；监视值是命中当时的快照。断点保存在本机 UserSettings；只为当前观察单位录制，历史按需增长到最近 4096 条，切换单位会开始新的记录。若观察者抛异常，窗口顶部会显示累计次数，可右键复制最近一次的完整堆栈；Play 时 Console 最多每 5 秒汇报一次新增异常。
- **调动画**：在动画 Details 配置混入／混出曲线；Section 的 transition 只用于非连续跳入。Playables 支持曲线、自定义曲线、Freeze、AvatarMask 及骨骼权重；未优化的 Generic 骨架且未接管根运动时，还能用 Inertialize 衰减上一姿势的偏移。Animator / Spine 使用各自支持的状态过渡，Legacy / 序列帧按可用接口定位，校验消息指出降级。在预览中选择前置动画或 Section 来源查看过渡；编辑器采样不执行玩法。Back 曲线作为混合权重时限制在 0–1，不产生姿势过冲。Generic 惯性按实际片段和角色骨架确定受动画控制的骨骼，装备替换片段也一样。首次遇到某个片段和骨架组合时会在临时骨架上采样并缓存。SkillAnimator 首次取 Driver 或显式预热才会创建播放图。禁用期间读取 Driver 会失败，SkillRunner 会在扣费前报告；此时调用 Prewarm 也不会创建驱动。可在加载阶段调用 `SkillAnimator.Prewarm(variant)`，或使用 `PlayableAnimationDriver.Prewarm(clip)`。先挂好装备、再预热；换装或更改骨架层级后要重新预热。无烘焙数据时，首次使用未知片段仍需在主线程采样。Generic 片段换装后只探测新出现的路径及其祖先，未改变的路径会复用上次结果；Humanoid 或根运动片段的未知组合仍可能需要完整探测。Legacy 片段同样缓存；在播放器里调用 SetCurve 修改它后，先用 `PlayableAnimationDriver.InvalidateClipBindings(clip)` 失效旧缓存，再预热。旧片段独占、或被新遮罩排除的骨骼会平滑回到基础姿势；身体遮罩未列出 Transform 时仍包含 Generic 骨骼，新的过渡没有任何匹配骨骼时通常使用交叉淡化；若上一次惯性尚未结束，即使新过渡时长为零，也先从屏幕上已有的姿势释放剩余偏移。技能结束、禁用 SkillAnimator 或切换后端时，技能释放自己改过的通道。Controller 没有驱动的武器或挂点回到装备设置的位置，包括播放中写入的新偏移。Controller 继续驱动的骨骼恢复当时的基础姿势。组件禁用或更换后端时，在活跃角色上已经开始的 Playables 播放会走技能配置的混出；在混出结束前重新启用同一后端，此时施放会从可见姿势继续混合；只重新启用或预热时，旧片段仍会按时退出，混出结束后不会延长下一次施放的混入。显式调用 SetBackend 表示重新配置，即便传入同一个对象也会在下次请求时换用新驱动。禁用整个角色、销毁，或变更后端配置后请求新驱动时会同步交还并截断旧播放。Play 中调整无关 Inspector 字段不会打断当前播放。在原生动画回调或手动采样期间首次预热／施放时，PlayableGraph 的创建和播放命令都延迟到采样结束；游戏逻辑仍走正常的施放检查。即使第二个技能或瞄准轨还在播放，旧片段已退出的骨骼也交还当帧的 Controller 或装备输入。 运行中要切换基础 Controller，可将它加入 Playables 后端的 `alternativeControllers`；预制体导入和场景构建会随 Controller 与层遮罩更新。动态创建后端时也可提供每层的遮罩数组（无遮挡的层填 null）。OverrideController 沿用基础 Controller 的表。未知 Controller 不会把未确认的层视为骨骼写入者。

对完整 Generic 骨架，使用 Always Animate 时，后端会检查基础 Controller 的每个状态及基础层遮罩。若它们始终写入技能所需的全部通道（例如位置的 XYZ），普通播放不监视该骨骼，也不接入交接作业。只有某一状态写过、只写部分轴、基础层含 Blend Tree／空状态、使用可变覆盖或无法确认时，仍跟踪技能挂点。惯性过渡及释放期间按需接入动画作业；稳定播放时，仅对技能独占或未能确认的挂点保留装备写入检查，包括跳过动画采样的帧。否则跳帧时装备设的新偏移可能被上一帧技能姿势盖掉。更换 Controller 或开启剔除会重新保护受影响的骨骼。

Humanoid 和 Optimize Game Objects 也交还可访问的额外挂点；肌肉和隐藏骨骼仍由 Unity 管理。场景构建和 Prefab 导入会记录骨架的原始路径，包括模型导入器在 Optimize Game Objects 前的层级。Resources 或内容包中临时加载的替换片段，也按实际片段在隔离骨架上采样并缓存，装备无需把每个挂点加入名单。后端的 exposedAttachments 是额外监视的挂点，与识别出的片段路径取并集。优化角色既没有完整的原始层级、又拿不到片段绑定路径时，会跟踪全部外露的非骨骼节点。即使手动指定了一个挂点，也不会排除其他未知挂点。如果优化后的 Animator 自己持续写入挂点默认值，释放后仍以它的原生行为为准。旧通道交还时按原生 Controller 当前有权重的片段确认哪些坐标轴有动画；即使采样值碰巧与旧技能相同，也保留这一帧的 Controller 输入。导入时已知的 Controller 会随角色保存层遮罩。播放器中若直接构造驱动且使用带遮罩的不同 Controller，可通过构造参数传入相应 Controller 和层遮罩。Animator 后端只有段尾实际会在入场混合结束前跳到非相邻段时才警告；打断并立即重放同一状态会直接定位，编辑器另有提示。连续中断混合时最多保留四层历史，超过时淘汰较小权重的历史姿势。
- **调命中和表现**：勾选「假人」「范围」，在「目标与表现预演」设置数量、排布、受击片段或片段替换表。「模拟投射物与区域」会画轨迹和区域周期；点「适应」可拖动查看动画后的任务。几何预演使用静止的球形碰撞代理（半径 0.18）、所选瞄准目标和手填的标签／属性样值。条件只走满足的一支，投射物按飞行轨迹与球体的接触顺序算命中。自定义假人模型仅改变外观；不会运行项目的阵营服务、障碍物遮挡、AI 或移动目标追踪。用真实运行的「事件」页确认最终命中。运行时片段替换从装备栈顶向下查找，再查技能替换表；空项及当前后端不支持的裸片段不阻断后续查找。震屏、减速与瞄准的项目服务可以由场景在施放时接入，未提供时校验显示提示。
- **动画降频**：Playables 的每 N 帧和每 N 秒模式默认对实例错相采样。使用技能根运动时强制逐帧更新。调度在普通 LateUpdate 之前发布姿势；自定义脚本若覆盖执行顺序，读取最终骨骼时应安排在调度器之后。
- **找内容**：Ctrl+Shift+F 查动作、标签、效果引用或参数。技能库「参数」页支持改显示名、查引用和拖到数值字段绑定。标签页可切换多个技能，「并排查看」开第二窗口后可拖动停靠。F 聚焦、Ctrl+D 复制选中节点，结构图 Ctrl+G 添加注释组；快捷键可在 Unity Shortcuts 设置中修改。
- **多人协作**：在「技能语义 Diff」保存共同基础快照，再把当前技能与另一方快照三方合并。无冲突可导出合并快照；冲突按稳定字段键列出，布局单列。导出的快照用于审查，不直接覆盖 Unity 资产。

### 通过技能资产统一施放

每个角色持有一个 `SkillRunner`，复用该角色的 ASC 与动画驱动。训练场、AI 或输入层只传入技能资产：

```csharp
var runner = new SkillRunner(owner, () => skillAnimator.Driver);
runner.Grant(abilityAsset); // 可预先授予；TryCast 首次使用也会自动授予
runner.MarkerReached += (asset, marker) => HandleSkillEvent(asset, marker);
var result = runner.TryCast(abilityAsset, targetAsc, taskContext);
```

`Grant` 按资产去重，各角色拥有独立 Spec。`TryCast` 返回 Core 的激活结果。技能在动画和能力归属任务都完成后结束；已发射的场景归属任务按自身寿命继续。HUD 使用 `IsActive(asset)`、`CooldownRemaining(asset)` 和 `CooldownDuration(asset)` 查询状态。

宿主推进 `owner.Tick(dt)`、提供目标和项目服务。召唤和命中使用资产上的强类型动作，重命名标记不改变执行。震屏、局部顿帧／全局变速、瞄准分别通过 Camera、Time、Rig 服务接入；没有服务时轨道不改变场景。已提交的消耗和冷却不自动退款。

### 通过 SkillAnimator 接入动画后端

角色挂载 `SkillAnimator`，在 Backend 下拉选择 Animator、Legacy Animation 或序列帧。驱动按需创建并缓存；已有手动创建 `IAnimationDriver` 的宿主仍可继续使用。

```csharp
var driver = character.GetComponent<SkillAnimator>().Driver;
var task = new AnimationTask(abilityAsset.Animation.Definition, driver,
    target: targetAsc);
owner.StartTask(spec, task);
```

`AnimationTask` 完成时只报告完成；宿主按技能生命周期决定是否结束能力。任务事件需要向构造函数的 `taskContext` 传入 `TimelineTaskContext`，提供 Origin、Searcher、目标和视觉对象池回调。内置 ProjectileSpawner / AreaEffectSpawner 会创建任务对象，这部分不承诺零分配。

`tagWindows` 在区间内计数授予标签，离开、打断和取消时回滚自己持有的计数；`taskEvents` 在指定时间调用可扩展的 `TaskSpawner`。同一帧跨过多个时间点时按边界顺序处理，命中回调能观察到该时刻的标签状态。

### Spine（可选包）

`Runtime.Spine` 和 `Editor.Spine` 通过官方 `com.esotericsoftware.spine.spine-unity` 包的 4.x 版本定义开启。未安装时不参与编译；已有 Spine 3.8 不会启用此适配器。角色选择 `SpineBackend` 后，编辑器自动枚举动画并支持姿态采样。

本次在独立 Unity 6000.3.14f1 工程中使用官方 spine-unity 4.2.120 / spine-csharp 4.2.37 实际编译并通过 PlayMode 测试。没有升级使用方项目中的 Spine 3.8。4.0/4.1 的包版本尚未实测。

## 编辑器：技能工作台

入口：`Window → ZFramework GAS → 技能编辑器`，或双击 `GameplayAbilityAsset`。旧的“技能结构图”菜单和 `SkillGraphWindow.Open().Show(asset)` 调用重定向到新窗口。

窗口采用与设计网页接近的深色三栏：左侧技能库和大纲，中间结构图／能力设置及多轨时间轴，右侧角色预览和 Details。分隔条记忆尺寸；窄窗口的预览和 Details 改为页签。

资产仍是唯一运行期数据源。`SkillDocument` 共享序列化对象、选择和播放状态；命令负责 Undo 分组。节点增量同步保留节点实例和视口。位置、注释、预览角色及游离引用写入主资产 importer userData，不增加运行期图解释器。

| 操作 | 行为 |
|---|---|
| 新建技能 | 近战、投射物、Buff、引导、召唤骨架五种模板 |
| Space／右键／端口拖到空白 | 创建内嵌资产或引用项目资产，并连接类型兼容的端口 |
| 双击节点 | 在 Project 中定位来源资产 |
| 删除连线 | 只清除该引用 |
| 删除内嵌节点 | 解除当前技能引用并删除子资产；其他文件仍引用时阻止删除 |
| 删除外部节点 | 解除当前技能引用，保留共享资产文件 |
| Ctrl+C/V/D | 复制粘贴／复制节点；内嵌子图深拷贝，外部资产保留引用 |
| C、F、A | 注释框、聚焦选中、显示全部；工具栏可自动整理 |
| 小地图 | 工具栏开关显示／隐藏右下角小地图，记住选择 |
| Details | 编辑所选资产或时间轴元素，并支持内嵌／外置转换 |
| 能力设置 | 标签门禁、调用方参数与门禁模拟器 |
| Ctrl+S、Ctrl+N、Ctrl+F | 保存、新建、搜索；Alt+左右键切换访问历史 |

消耗必须 Instant，冷却必须授予标签，子效果禁止自引用、重复挂载、循环和超过八层的链路。不兼容端口在拖线时不可连接，并提供原因提示。动画事件端口按稳定 ID 绑定，数组重排不改变身份。Cue 以只读标签条显示在效果或动画节点内部，点击动画 Cue 条会选中对应时间轴区间；数组重排后仍按稳定 ID 定位。

没有保存坐标的新节点会等待实际尺寸测量完成，从父节点右侧向下寻找空位；搜索菜单或拖入资产时的落点作为起点。已保存或手动摆放的节点不自动移动。只有主动点击「自动整理」才会重排全部节点：按引用层级分列、按父节点位置排序，并为节点实际高度留出间距。布局存在主资产的导入设置中，不给技能运行数据添加坐标或行号。

节点采用深色标题与顶部类型色条，输入端口收进标题左侧，输出端口紧凑排列。节点内仅保留直接绑定的策略、时长、周期或片段、循环字段，不显示 Inspector 的分组标题；编辑仍支持撤销并同步 Details。Cue 标签条与时间轴使用同一 Cue 基色。

属性词表用 `AttributeCatalogAsset` 配置；没有词表时保留整数输入。带 `[AttributeCatalogSource]` 的代码常量可从菜单生成词表。Magnitude、修改器、SetByCaller 和 SerializeReference 后端／任务策略提供专用编辑控件。

### 运行时调试与技能编辑器联动

Play 后打开 **Window → ZFramework GAS → 运行时调试**。默认跟随 Hierarchy 选中对象，会向父级查找实现 `IAbilitySystemProvider` 的组件；关闭「跟随选中」后，从单位菜单固定观察对象。刷新周期为 0.1 秒，暂停游戏时也可观察当前状态，退出 Play 或销毁单位会清空显示。

窗口显示技能的激活、等级、标签门禁与冷却；动画任务的实际时长和授权时间；标签计数与新增提示；属性基础值、当前值和差值；持续效果的剩余时间、实际总时长、周期、层数与来源。没有正数冷却时长时隐藏冷却条，非周期效果省略周期文字；技能内嵌效果按「技能名 / 效果名」显示。技能行的「可尝试施放」只表示未被标签和冷却拦住，不代表资源一定足够。

点击技能行打开技能编辑器，再勾选 Play 模式下可用的 **跟随运行时**。当前技能匹配运行中的动画任务时，本地播放暂停，青绿色播放头跟随 `NormalizedTime × 运行中定义的授权时长`；没有匹配任务时仍可本地播放预览，快照刷新不会打断它。结构图为激活能力和当前生效效果描边。多个技能共享动画时优先跟随当前根技能的任务。关闭开关、切换到没有匹配任务的技能，或停止 Play 后解除播放头联动；停止观察时也会清除图中高亮。

联动只更新播放模型和样式，不写资产、不创建 Undo。预览视口仍然是 Clip 的采样姿势，不是现场 Animator 混合状态的镜像。运行中的定义通过 `DefinitionSource` 弱键表查回来源资产，因此编辑资产导致缓存失效后，旧任务和旧效果仍可被正确识别。迷你时间轴读取任务持有的旧定义，主时间轴显示当前编辑中的资产；Play 中修改结构时，两者可能不同。

自动化覆盖见 `RuntimeDebugTests` 与 `RuntimeDebugPlayModeTests`。后者在编辑器测试程序集中进入真实 Play，加载生成的 BasicCombat 场景，验证斩击、霸体标签、冷却、选中/固定单位和编辑器联动；退场后恢复测试域，避免示例标签注册表影响其他用例。

### 多轨时间轴与预览

支持动画、事件、Cue 区间、标签窗口和任务事件轨道。片段下拉从预览角色解析，选择片段时同步长度、帧率，并等比调整已有时间点。Animator 使用配置的层，递归子状态机，支持 Override Controller；BlendTree 使用第一个子片段作近似预览并提示。

Cue 区间按标签分组，行头显示标签名（悬停可看完整标签），点击行头折叠／展开。同标签内重叠区间和标签窗口自动分层，轨道高度随层数增长；相邻区间首尾相接可复用一层。事件点也会避让，相同时刻显示数量角标。拖动期间冻结行号，松手后重排，仍然只产生一步撤销。在某个 Cue 行双击或右键添加区间，会沿用该行标签。同标签的有效区间重叠时，校验给出 `GAS015` 警告，提示确认重复触发是否符合预期。

空轨道默认隐藏，可从「+ 轨道」菜单添加第一个元素。行头以类型色竖条和名称标识，仅 Cue 组保留折叠箭头。刻度采用 0.05、0.1、0.25、0.5、1 秒等整齐间隔，拖动仍按动画帧率吸附。片段名绘制在混入斜坡上方，避免被压暗。

| 操作 | 行为 |
|---|---|
| 拖刻度／播放头，Space | 定位姿态，播放／暂停 |
| 轨道区滚轮 | 上下滚动轨道 |
| 刻度区滚轮／Ctrl+滚轮，中键拖动 | 缩放、平移 |
| 拖事件或区间，拖区间两端 | 修改时间、整体移动、调整起止 |
| Ctrl／Shift 选中，空白处拖框 | 多选；拖动选中组整体移动 |
| Alt+拖动 | 关闭吸附；默认吸附到帧、相邻元素或播放头 |
| 双击轨道／右键 | 添加元素；从大纲拖效果到事件轨道也可添加 |
| 拖动混入、混出手柄 | 动画条起点的斜坡与末尾的淡出尾巴显示过渡长度；拖动两端手柄或在片段行输入「混入」「混出」调整，按帧吸附，抬手一步撤销 |
| M、R | 在播放头添加事件；两次 R 标记 Cue 区间起止 |
| 逗号／句号、Home／End | 前后逐帧、首尾定位 |
| Ctrl+C/V、Delete | 复制、粘贴到播放头、删除选择 |

拖动过程只更新视觉位置，抬手一次写回并形成一步 Undo。时间轴元素的稳定 ID 由编辑器自动维护，用于保持数组重排后的端口和选择对应关系。

预览使用隔离的 PreviewRenderUtility 场景，不驱动战斗规则。拖动旋转、滚轮缩放、双击聚焦。预览角色上的 `CueVfxPlayer` 引用 `CueVfxLibrary`，运行时与编辑器读取同一份 Cue → 特效 Prefab／挂点／跟随／停止方式映射。普通粒子无需自定义脚本；自定义网格可继承 `CueVfxBehaviour`。`ICuePreview` 仍可用于其他项目扩展。顶部后端菜单切换预览角色上已有 SkillAnimator 的策略。

通过 Create → ZFramework GAS → Cue VFX Library 创建映射资产，再赋给角色的 Cue VFX Player。挂点为相对该组件的 Transform 路径，留空表示根节点；不跟随时保留区间开始那一刻的挂点世界变换（不自动贴地或射线投射）。运行时在创建 ASC 后调用 `player.Bind(asc)`，组件自动注册 Cue 并在 LateUpdate 推进表现；禁用、销毁和重新绑定会清理所有实例与监听。映射使用精确标签匹配，只处理 OnActive／Removed 区间事件。相同标签重叠区间共用一组实例，计数归零时停止。

立即移除会在区间结束／技能打断时清理；停止发射模式保留剩余粒子，直到粒子死亡或超过尾迹最长时间。预览可任意前后拖动，粒子使用固定随机种子从零模拟，并展示停止后的尾迹。固定在世界的特效从区间开始姿势定位。内置支持 ParticleSystem 和显式采样的 CueVfxBehaviour；自定义 MonoBehaviour、VFX Graph、音频与特效内部 Animator 不会自动获得时间轴预览。

### 校验与示例

消息页提供 GAS001–004、010–013、020–022、030–032 检查、定位和适用的自动修复。需用户选择的配置仍在 Details 中处理，不会猜测标签或资产。菜单 `Tools → ZFramework GAS → 校验所有技能` 可批量检查；CI 可调用 `ZFramework.GAS.Editor.BatchValidate.Run`，存在错误时退出码非零。批量校验不会为资产补 ID。

`Tools → ZFramework GAS → 创建 BasicCombat 示例` 一次生成五种技能、属性词表、骑士预制体、Animator 动作、独立特效 Prefab 及 Cue 特效映射库，并自动接好角色和技能预览，全部位于 `Assets/GAS Samples/BasicCombat`。斩击包含刀光 Cue、霸体和连招窗口；战吼包含独立地面粒子法阵。已有示例目录会在确认后重新生成；已打开的示例场景会重新载入生成结果。标签注册与宿主接入见 `Samples/BasicCombat/README.md`。
