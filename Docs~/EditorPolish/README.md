# 技能编辑器视觉整理

2026-11-02，在 Unity 6000.3.14f1 的 `Testproject/GASRefactorValidation~` 验证工程中打开 BasicCombat 生成的「战吼」，执行自动整理后采集。图片来自 Unity 编辑器窗口自身的渲染缓冲，分别裁取结构图、时间轴；不是网页效果图。

## 结构图

深色标题加类型色细条；输入连接点位于标题左侧；端口容器透明。内联字段直接绑定序列化属性，省略 Inspector 的 Header。Cue 标签条使用 `SkillColors.Cue` 的浅底色和细边框。小地图固定右下角，隐藏标题，工具栏可以关闭。

## 时间轴
