## 实施范围

| 计划部分 | 本轮实现 |
|---|---|
| 第一阶段：配置闭环 | 强类型动作、激活动作与时间轴动作列表；统一选敌、参数／等级快照、受限伤害公式、预检查失败定位；投射物／区域／召唤的独立场景生命周期 |
| 第二阶段：复用 | 独立动作模块、共享参数集、参数变体、AbilitySet、展示名／描述／图标、模块标签页及引用范围 |
| 第三阶段：事件与连招 | Gameplay 事件与 Cue 分离；延时、等待事件、等待目标及成功／超时／取消出口；稳定 ID 的 Section、默认下一段及输入缓冲 |
| 第四阶段：动画与预览 | 可选 Playables、独立片段速度、AvatarMask 与 LayerMixer；曲线／音效／自定义运行期轨道；范围、线框假人、前后帧和根位移预览；根运动移动适配接口 |
| 第五阶段：生产工具 | 冷却与展示名批量配置、资产／标签引用结果、语义 Diff、图内搜索、对齐／等距、书签、折叠持久化、隐藏未连接端口、编辑器重路由点 |
| 调试与性能 | 参数／动作／独立任务／具体失败原因；动作边界暂停请求及整场景逐帧；依赖缓存失效、增量索引、虚拟化技能库、按稳定 ID 更新相关时间轴元素 |

Core 仍是纯 C#，Unity 层负责物理、Prefab、音频与动画。保留现有公开入口；没有新增迁移功能、图解释器或字符串公式执行器。

## 性能基线

原始机器信息及指标保存在 [SkillPerformanceBaseline.json](SkillPerformanceBaseline.json)。热操作取 40 次的 P95；Undo／Redo 取 10 次，冷操作取一次。冷操作指此 Unity 进程的首次索引／窗口访问，不含 Unity 进程启动。

| 操作 | 耗时 | 平均托管分配次数／操作 | 首轮预算 |
|---|---:|---:|---:|
| 冷搜索 500 技能 | 194.7ms | 14,001 | 仅记录 |
| 热索引搜索 | 3.4ms P95 | 2 | ≤100ms |
| 冷打开 100 节点窗口 | 1,010.9ms | 215,788 | 仅记录 |
| 热搜索及可见列表更新 | 39.5ms P95 | 8,329 | ≤100ms |
| 普通字段更新 | 2.2ms P95 | 257 | ≤50ms |
| 节点位置更新及同步重绘 | 11.3ms P95 | 1,175 | ≤33ms |
| Undo 与 Redo 往返 | 437.8ms P95 | 83,191 | 仅记录，仍需优化 |

拖动指标测量位置更新和同步 GUI 重绘的 CPU 耗时，不含操作系统输入延迟及 GPU 呈现。测量环境启用了 Editor Profiler，结果带有采集开销。

此 Unity Mono 上 `GC.GetAllocatedBytesForCurrentThread()` 不能可靠报告字节数，因此使用 `GC.Alloc` 的 ProfilerRecorder **记录次数**。记录器先用真实分配做探针；缓存饱和返回不可用，不将其误报为零。这里不提供未经验证的 Unity 分配字节数，也不宣称施放启动、对象生成或编辑器零 GC。

## 明确的限制与待验收

- 独立策划按文档配置五类技能的可用性验收尚未开展，不能用开发者自动测试替代。
- 未执行 IL2CPP 构建；本轮 Unity 验证使用 Editor／Mono。主工程原有 Spine 3.8 未升级；独立验证工程保留官方 Spine 4.2 后端测试。
- 预览假人是尺寸与距离参照，不模拟命中或阵营。根位移轨迹取片段采样；原地动画、根位移已烘焙入姿态或特殊嵌套 Rig 仍须结合项目角色控制器验证。
- 编辑器音效是试听接口，不等同于运行期空间混音。项目移动、对象池、阵营及目标选择服务仍需要项目接入。
- 动作边界申请暂停后，Unity 在当前世界帧结束时暂停，同一同步动作批次会完成；不支持挂起任意 C# 调用栈。逐帧推进整个场景。
- 批量配置首版覆盖冷却与展示名；更多业务字段可在现有表格窗口扩展。Undo／Redo 仍有约 438ms 的规模开销。
- 没有扩大到 2D、联网预测、任意脚本执行、完整蓝图系统或游戏内悬浮调试面板。
