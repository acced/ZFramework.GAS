ZFramework GAS 技能编辑器改进方案

在现有「三栏工作台 + 结构图 + 时间轴 + 预览 + 运行时调试」基础上，分五个阶段补齐与 UE 蓝图编辑器、团结 AnimGraph 1.0.0 的差距。数据格式保持兼容，每个阶段独立交付、独立验收。

00结论摘要

5 个阶段
约 13 周，P5 的后 3 项可随时插入
3 处核心差距
混合硬切、逻辑不可视、调试无数据
0 次格式破坏
只新增字段，流程图是现有数组的投影
0 B 热路径分配
调试钩子无订阅时只做一次空判断

动画混合是硬切／线性

Section 跳转直接硬 Seek AnimationTask.cs:213；混合只有线性 CrossFade PlayableAnimationBackend.cs:147-161；遮罩按后端全局一份 :87。

技能逻辑不可视

SkillAction 是 SerializeReference 嵌套数组，只能在 Details 里折叠编辑；结构图节点是资产，表达的是引用关系，看不出执行顺序和分支。

调试只能停住，看不到数据

断点只能在运行时窗口按 ID 设；暂停时没有参数、目标等监视值；没有执行路径高亮和事件历史，时序问题只能打日志。

P1动画混合与遮罩

优先级 1约 2 周运行时编辑器

目标：Section 跳转不再跳姿态；混入、混出和段落过渡可以选曲线和模式；遮罩可以按技能配置。

3. AnimationTask 接入

  • 构造 AnimationTask.cs:119：有 IAdvancedBlendingDriver 时传入 BlendInSpec，否则走现有时长接口。
  • 段落跳转 :213：目标段配置了 transition 且驱动支持时调用 SeekBlend，否则硬 Seek。标记、窗口、Cue 的时间轴语义完全不变，只改姿态。
  • 结束 :359：传入 BlendOutSpec。

4. 按技能遮罩：双技能层交替

PlayableGraphPlayable 驱动改造后
  • SkillAnimationAsset 新增 AvatarMask mask、bool additive、float layerWeight = 1，留空沿用后端设置。
  • 新技能总在空闲层上设置自己的遮罩，旧技能在原层上带着原遮罩淡出，所以「上半身技能」接「全身技能」时不会出现遮罩突变。
  • 非 Playable 后端忽略该设置，由校验提示。按骨骼加权遮罩放到 P4，和 Aim Offset 共用作业基础设施。

5. 编辑器

▶适配动画 · 连斩前置动画：待机 ▾
  • 时间轴 BlendRamps TimelinePanel.cs:341 按曲线画斜坡、按模式着色；Section 起点画出跳入过渡。

6. 校验与测试

新增校验

  • 过渡时长超过段长 → 错误。
  • 后端不支持所选曲线、模式或 SeekBlend → 警告，并说明降级结果。
  • 非 Playable 后端配置了技能遮罩 → 警告。

测试

  • Editor：Playable 真实图上的曲线权重、两层遮罩交替、SeekBlend 输入数量与权重守恒、降级路径。
  • PlayMode：Section 跳转那一帧骨骼位移低于阈值（证明不跳姿态）；Animator 后端 SeekBlend 的偏移正确。
  • Core 零分配断言保持。

03风险与对策

风险等级对策
Inertialize 作业实现难度（骨骼偏移衰减、根运动一致性）高P1 先交付曲线、Freeze、SeekBlend；Inertialize 作为第二步，只在 Playable 后端提供，失败时降级 CrossFade。
GraphView 是实验性 API中流程图与结构图共用一层封装；数据仍是数组，视图可替换，不会锁死数据格式。
双技能层改变 Playable 图结构中保留现有测试（权重守恒、Trigger 交接、根运动归属），新增遮罩交替测试后再替换。
IL2CPP 裁剪 SerializeReference 子类中link.xml + 冒烟构建；项目自定义动作需在文档中说明加入 link.xml。
调试钩子影响热路径低静态事件 null 检查；Core 零分配断言覆盖。
预览模拟与运行时不一致低几何判定复用 TargetQuery 定义；模拟参数取自同一份动作定义；差异在文档中标注为「近似」。
